
# TaskFlow — Productivity Task Manager

A responsive productivity app built with HTML, CSS, and vanilla JavaScript.

## Features
- Create, view, edit, and delete tasks
- Categorize tasks as Work, Personal, Study, or Other
- Assign due dates and identify overdue tasks
- Filter by All, Active, and Completed
- Search tasks by name or category
- Persist tasks with browser localStorage
- Responsive layout and completion animations

## Run locally
Open `index.html` using VS Code Live Server.

## Technologies
HTML5 · CSS3 · JavaScript ES6+ · DOM · localStorage

## Data storage
Tasks are stored in this browser's localStorage. They are not synchronized between browsers or devices.
