
# Weather Telemetry Dashboard

A responsive weather application that searches global cities and displays current weather conditions and a five-day forecast using the OpenWeatherMap API.

## Features
- Global city search
- Live temperature and weather conditions
- Humidity, wind speed and atmospheric pressure
- Five-day forecast cards
- Celsius and Fahrenheit conversion
- Dynamic weather backgrounds and icons
- Loading states and invalid-city error handling
- Responsive mobile layout

## Technologies
- HTML5
- CSS3
- JavaScript
- Fetch API and async/await
- OpenWeatherMap API

## Run locally
1. Clone or download this repository.
2. Open `index.html` using VS Code Live Server.
3. Configure your own API key locally in `script.js`.

**Security:** Do not commit real API keys to a public repository. For public deployment, use a backend proxy or another secure approach to keep the key off the client.
